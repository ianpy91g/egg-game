# 捏蛋大挑戰（網頁版）

用 ORIORI 握力球捏破 10 種由小到大的蛋：麻雀蛋 → 恐龍蛋。破完 10 關會出現特別關「奇異鳥蛋」（一般模式握力 60，兒童 36、困難 75），捏破後孵出 Kiwi Trip 的 Kiwi（`kiwi.png`：kiwi10.blend 正面攝影機以 EEVEE 扁平算圖，拿掉毛髮、只用模型原本的兩種頂點色）。

**開始玩：** https://ianpy91g.github.io/egg-game/

- 握力超過門檻並撐住 0.5 秒就能捏破蛋，每關 5 次機會。
- 每次都從第 1 關開始，不能選關；某關失敗時可以按「再挑戰」從那一關接關，回選單就重新從第 1 關開始。
- 不保存過關進度：重新整理網頁後一律從零開始（只記住難度與音樂開關）。
- 三種難度（選單左下角按鈕切換，進度與紀錄分開記）：
  - 兒童：門檻 ×0.6（6～33）
  - 一般：第 1 關 10，每關多 5（10～55）
  - 困難：門檻 ×1.25（13～69）
- 背景音樂是程式即時合成的 8 小節循環，選單右上角可以開關（鍵盤 M）。
- 選單按「連接握力球」，選擇 `weixin-` 開頭的裝置。沒有握力球時，遊戲中按住畫面也能玩。
- 捏一下握力球＝按「下一步」（開始、下一關、再挑戰）。

## 檔案

- `game.js`：遊戲本體（畫圖、邏輯、音效），不碰 DOM，可在 Node 測試
- `index.html`：很小的外殼，每次開啟都在網址加時間載入下面兩個檔，避免 Bluefy 拿到快取的舊版
- `app.js`：畫面縮放、觸控、Web Bluetooth（服務 `FFB0`、握力通道 `FFB2`）、存檔（localStorage）
- 發佈新版時記得改 `game.js` 的 `VERSION`，選單右下角會顯示

握力球資料格式：ASCII `"19" + 方向(1=用力/0=放鬆) + 握力值`，例如 `19128.0`。
